Subscribe prints a stream of messages as JSON lines.

Usage:

  yat subscribe PATH

Flags:

  -limit, -n 0
      Stop after n deliveries.

  -duration, -d 0s
      Stop after some amount of time.

  -data-format, -F string
      Controls the format of the printed data field.
      Supported formats are base64, string, json, and raw.
      The raw format prints the message data instead of a JSON line.
